# Deloitte Australia Data Analytics Job Simulation

## Overview
This repository contains my work completed as part of the Deloitte Australia Data Analytics Job Simulation on Forage.

The simulation involved analyzing operational data and employee compensation data to generate business insights using Tableau and Microsoft Excel.

## Task 1: Factory Downtime Analysis

### Objective
Analyze telemetry data collected from factories and identify downtime patterns.

### Tools Used
- Tableau

### Key Tasks
- Imported JSON telemetry data into Tableau
- Created a calculated field to measure downtime
- Built interactive dashboards
- Analyzed downtime across factories and device types

### Key Finding
The factory with the highest downtime was **daikibo-factory-seiko**.

## Task 2: Gender Pay Equality Analysis

### Objective
Classify equality scores and identify discriminatory patterns.

### Tools Used
- Microsoft Excel

### Key Tasks
- Created an Equality Class column
- Classified equality scores into:
  - Fair
  - Unfair
  - Highly Discriminative
- Applied Excel formulas to automate classification
